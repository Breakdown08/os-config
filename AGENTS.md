# os-config

Ты настраиваешь рабочую машину Кирилла: NixOS, niri, neovim, терминал. Твоя задача — делать конфигурацию, которой приятно пользоваться каждый день: минимальную, быструю, управляемую с клавиатуры. Репозиторий публичный и читается как витрина.

Команды — в `README.md`. Структура: `nixos/` — система, `home/` — stow-пакет для `~`, `secrets/` — секреты в игноре.

## К чему стремимся

- **Минимализм.** Меньше пакетов, модулей и строк. Прежде чем добавить, проверь, что уже установленное этого не умеет. Новое заменяет старое, а не ложится рядом.
- **Удобство важнее красоты.** Частое действие — одно сочетание клавиш. Мышь не должна быть обязательной.
- **CLI и TUI вместо GUI.** Предлагай инструмент терминала, когда он не хуже: выбирай простой, поддерживаемый, с разумными настройками по умолчанию.
- **Хоткеи согласованы.** Vim-движение `hjkl` везде, где это возможно. Новое сочетание не конфликтует с существующими и записано в `README.md`.
- **Декларативность.** Всё, что можно, описано в репозитории и воспроизводится на новой машине. Ручных шагов нет либо они в `README.md`.
- **Предлагай.** Заметил, что настройку можно упростить или рутину убрать хоткеем, — скажи.

## Как работать

- Перед изменением системы вычисли конфиг и сверь с запущенной:
  `nix eval --raw './nixos#nixosConfigurations.nixos.config.system.build.toplevel.outPath'` и `readlink -f /run/current-system`. Рефакторинг путь не меняет.
- Проверка сборки без применения: `nixos-rebuild build --flake ./nixos --no-link`. Конфиг niri: `niri validate`.
- Новый файл в `nixos/` сначала `git add`: flake видит только файлы, известные git.
- Применяет Кирилл: `sudo nixos-rebuild switch`, для рискованной правки сначала `sudo nixos-rebuild test`.
- Коммиты: Conventional Commits на английском. Push за Кириллом.
- Перед каждым коммитом — `git status`: только те файлы, которые ты менял.

## Границы

- Никаких секретов, токенов и рабочих адресов в git и в `.nix`: репозиторий публичный, `/nix/store` открыт на чтение. Значения в `secrets/` не читай.
- Пароль sudo не отключать: пересборка без него дала бы root любому процессу.
- Не менять `system.stateVersion`.
- Сессия Cinnamon остаётся запасной, пока Кирилл не решит иначе. Правка, из-за которой нельзя войти в систему, — самая дорогая ошибка.
- Смена дисплейного менеджера, загрузчика, разметки — только по слову Кирилла и через `test`.

## Открыто

Под niri проверить вживую: вход из LightDM, буфер обмена между X11 и Wayland, демонстрацию экрана, предпросмотр handbinder.
