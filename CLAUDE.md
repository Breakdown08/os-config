# os-config

Конфигурация NixOS и домашние настройки Кирилла. Репозиторий публичный. Команды — в `README.md`.

## Работа

- Перед изменением системы вычисляй конфиг и сверяй с запущенной:
  `nix eval --raw './nixos#nixosConfigurations.nixos.config.system.build.toplevel.outPath'` и `readlink -f /run/current-system`. Рефакторинг путь не меняет.
- Проверка сборки без применения: `nixos-rebuild build`.
- `nixos-rebuild switch` запускает только Кирилл: нужен sudo. Безопасный первый шаг для рискованной правки — `sudo nixos-rebuild test`.
- Коммиты: Conventional Commits на английском, без `Co-Authored-By`. Push — за Кириллом.

## Границы

- Никаких секретов, токенов и рабочих адресов в git: это публичный репозиторий, а `/nix/store` открыт на чтение. Секреты живут в `secrets/`, значения не читай.
- Пароль sudo не отключать: пересборка без него дала бы root любому процессу.
- Не менять `system.stateVersion`.
- `~/.profile` не в репозитории.

## К чему стремимся

- Одна простая команда на пересборку; всё нужное для новой машины описано здесь.
- Настройки программ — в `home/`, система — в `nixos/`, версии закреплены: `flake.lock` и `lazy-lock.json`.
- Wayland (niri) рядом с Cinnamon на X11: сначала проверить Godot, камеру, буфер обмена и демонстрацию экрана, затем решать.
